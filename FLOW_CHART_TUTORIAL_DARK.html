1) End-to-End Data Flow

Step A
User uploads image in New Scan.
Step B
Frontend auto-calls POST /api/v1/image/validate.
Step C
Backend calculates quality metrics: sharpness, lighting, framing.
Step D
Grade returned: Sharp / Acceptable / Marginal.
Step E
If allowed, user submits image.
Step F
Frontend compresses to WEBP 1024x1024 quality 82.
Step G
Backend upload route stores image, creates scan_id.
Step H
Backend runs condition scoring immediately (OpenCV + NumPy heuristics).
Step I
Optional GPT-4 side-by-side runs in parallel (if enabled).
Step J
Condition payload saved in SQLite, then shown in Results/History.

2) Frontend Correlation

  • Main routing: frontend/app.py (New Scan, Results, History)
  • Upload + state machine: frontend/components/uploader.py
  • API client wrappers: frontend/utils/api_client.py
  • Results rendering: frontend/components/results.py
  • History rendering: frontend/components/history.py
Session state keeps current api_url, quality cache, file token, upload state, and scan_id for Results fetch.

3) Backend Correlation

Upload/Validate pipeline

  • Route entry: backend/routes/upload.py
  • File guardrails: backend/utils/helpers.py (types + max 15 MB)
  • Quality metrics: backend/services/image_processor.py
  • Image process/compress: process_image() in same service

Condition analysis pipeline

  • Main logic: backend/services/ai_service.py
  • Defect heuristics: rust, cracks, dents, stains, wear/aging
  • Score + severity + recommendation derived from weighted penalties

Persistence and retrieval

  • SQLite service: backend/services/sqlite_service.py
  • Condition routes: backend/routes/condition.py
  • Startup env load: backend/main.py reads project .env

4) OpenCV + NumPy in Simple Terms

  • OpenCV: builds masks/contours/edges from pixels.
  • NumPy: computes numeric ratios/statistics (means, thresholds, penalties).
  • Both together give fast rule-based scoring, but not true semantic understanding.
This is why GPT-4 side-by-side was added: OpenCV provides deterministic baseline, GPT can provide semantic interpretation when available.

5) Demo Run Checklist

  1. Start backend and frontend on fixed ports.
  2. Set frontend API endpoint to backend URL.
  3. Upload image and confirm quality grade appears.
  4. Submit image and verify scan_id is generated.
  5. Open Results and click Get Condition Result.
  6. Verify main analysis + GPT-4 section status.
